# Annotation protocol

Only 4 classes exist. There is no separate class for logo/text/sticker/
ring/design — those are part of Class 1 and get recolored along with the
rest of the cover.

## Class 0 — Background
Everything outside the phone/back-cover object.

## Class 1 — Editable rear-cover surface (includes logo/text/sticker/ring/design)
The physical rear-facing cover surface that should change color. This
includes:
- Main cover material, texture, natural gradients/highlights belonging to the cover
- Logo, brand name / mobile brand text, printed or decorative text
- Stickers, printed rings, MagSafe-style rings, decorative patterns
- Any other marking physically printed or attached on the back cover

None of the above gets its own class. If it's printed on the back cover,
it's Class 1, full stop — the recolor must cover it too.

## Class 2 — Complete camera box/module + hardware
The entire visible camera island/box/module is protected. Include its
housing, lenses, rings, flash, sensors and any hardware within the module.

If a logo/text/ring-looking mark is physically part of the camera module
(printed on the housing, not the cover), classify it as Class 2, not Class 1.

## Class 3 — Frame / sidewalls / buttons / ports
Any visible side rail, edge wall, top/bottom edge, buttons, charging port,
speaker openings and similar hardware.

## Boundary rule
At ambiguous boundaries, prefer protected (Class 2 or 3). Inspect at
200–400% zoom. Never expand Class 1 into camera housing or frame.
